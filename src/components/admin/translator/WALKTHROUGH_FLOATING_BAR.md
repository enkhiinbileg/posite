# Webtoon Editor: Floating Command Bar & Fixes

Энэхүү шинэчлэлтээр **Floating Command Bar** (Хөвөгч Цэс) болон хэд хэдэн чухал засваруудыг хийлээ.

## 1. Floating Command Bar (Хөвөгч Цэс)
Хулганыг дагаж (эсвэл сонгосон объектын дэргэд) гарч ирэх ухаалаг цэс.

### Хэрхэн ашиглах вэ:
*   **Текст засварлах үед (Select Text)**:
    *   Текстэн дээр дарахад цэс автоматаар гарч ирнэ.
    *   **Features**: Фонтын хэмжээг томруулах/жижигрүүлэх, Bold/Italic болгох, Устгах (Trash).
*   **Баллуурдах үед (Eraser)**:
    *   Eraser сонгогдсон үед цэс хулганыг дагана.
    *   **Features**: Баллуурны хэмжээг тохируулах Slider.

## 2. Засварууд (Fixes)

### LAYERS Tab
*   Хажуугийн самбар дахь "Давхарга" табын нэрийг **"LAYERS"** болгож өөрчиллөө. Ингэснээр нэр тасарч харагдах асуудал шийдэгдсэн.

### OCR (Text Scanning)
*   "Error scanning" алдааг зассан.
*   "Text Recognition (AI)" тохиргоог идэвхжүүлсэн үед **Local OCR (Tesseract)** ашигладаг болсон. Сервер талын алдаанаас сэргийлж, найдвартай ажиллагааг хангана.
*   Тохиргоог унтраасан үед зөвхөн хоосон бөмбөлөг үүснэ.

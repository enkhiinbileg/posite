# Webtoon Editor: Шинэ Боломжуудын Заавар

Энэхүү баримт бичигт Advanced Webtoon Editor-т шинээр нэмэгдсэн **Хуваагдмал Дэлгэц (Split View)** болон **Давхаргын Систем (Layer System)**-ийг хэрхэн ашиглах тухай тайлбарласан болно.

## 1. Хуваагдмал Дэлгэцийн Горим (Split View)
Дэлгэцийн доод хэсэгт байрлах хэрэгслийн мөрөнд (Control Bar) харьцуулан харах шинэ товчлуур нэмэгдсэн.

### Хэрхэн ашиглах вэ:
1.  Дэлгэцийн доод хэсэгт байрлах багажнуудыг олоорой.
2.  Томруулах (Zoom) хэрэгслийн хажууд байрлах **Хамгийн зүүн талын товчлуур** (Icon: `LayoutTemplate`) дээр дарна.
3.  **Идэвхэжсэний дараа**: Дэлгэц хоёр баганад хуваагдана:
    *   **Зүүн Багана (Original)**: Эх зургийг орчуулгагүйгээр, эх хувиар нь харуулна. (Зөвхөн харах зориулалттай).
    *   **Баруун Багана (Editor)**: Орчуулга хийх, бөмбөлөг зөөх, цэвэрлэгээ хийх үндсэн ажлын талбар.
4.  **Синхрончлол**: Хоёр багана зэрэг гүйлгэгдэж (scroll), зэрэг томорч/жижигрэх (zoom) тул харьцуулж ажиллахад хялбар байна.

### 🔍 Томруулах/Жижигрүүлэх (Zooming)
*   **Shortcut**: `Ctrl` товчлуурыг дарж байгаад хулганы бөмбөлгийг (Scroll Wheel) эргүүлнэ.
*   **Товчлуур**: Доод талын самбар дахь `+` `-` товчлууруудыг ашиглаж болно.

## 2. Давхаргын Систем (Layer System)
Баруун талын самбарт (Right Sidebar) давхаргын удирдлагын систем нэмэгдсэн бөгөөд энэ нь элементийн харагдах байдал болон засварлах эрхийг хянах боломжийг олгоно.

### Давхаргууд (Layers):
1.  **Text Layer (Текст)**: Орчуулсан текст болон скриптүүд энд байрлана.
2.  **Clean / SFX Layer (Цэвэрлэгээ)**: Гараар зурсан зураас, баллуурдах үйлдлүүд болон SFX цэвэрлэгээнүүд энд хадгалагдана.
3.  **Original Layer (Эх зураг)**: Үндсэн эх зургууд.

### Хэрхэн ашиглах вэ:
1.  **Баруун Самбар (Right Sidebar)**-ыг нээнэ үү.
2.  **"LAYERS"** табыг сонгоно уу (Хэрэв харагдахгүй бол Translate табын доор эсвэл тусдаа таб хэлбэрээр байрлана).
3.  **Харагдах байдлыг солих**: Нүдний icon (`Eye`) дээр дарж тухайн давхаргыг нуух эсвэл харуулна.
    *   *Жишээ: "Text Layer"-ийг нууж, доорх цэвэрлэгээгээ (clean) шалгах.*
    *   *Жишээ: "Clean Layer"-ийг нууж, эх текстийг харах.*
4.  **Түгжих (Lock)**: Цоожны icon (`Lock`) дээр дарж санамсаргүй өөрчлөлт хийхээс сэргийлнэ.
    *   **Text Locked**: Текстийг зөөх, сонгох боломжгүй болно.
    *   **Clean Locked**: Зургийн хэрэгслээр (Eraser/Brush) санамсаргүй зурахаас сэргийлнэ (харагдах байдал).
    *   **Original Locked**: Эх зураг үргэлж түгжээтэй байдаг ч, давхар баталгаажуулах боломжтой.

## 3. Мини-Навигац (Mini-Navigator)
**"Text Layer"** хэсэгт бүх текст объектуудын жагсаалтыг харах боломжтой.
*   Жагсаалтаас аль нэг текстийг сонгоход дэлгэц тухайн текст дээр автоматаар очиж (scroll to), идэвхжүүлнэ.

## Техникийн Тэмдэглэл
*   **Хурд**: Давхаргыг асааж унтраах үйлдэл нь агшин зуур хийгдэх бөгөөд зургийг дахин ачаалах шаардлагагүй.
*   **Төлөв хадгалалт**: Давхаргын тохиргоо (харагдах/түгжих) нь одоогоор түр санах ойд хадгалагдах тул хуудсыг шинэчлэхэд (reload) анхны төлөвтөө орно.
